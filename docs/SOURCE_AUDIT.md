原生源码保持原工程字节不变。适配集中在 Python 工具：独立构建入口、编译器发现、资源路径参数、发行文件名、校验文件和用户说明的原样复制。没有改动汉化运行逻辑。

仓库根 README 没有被替换，也没有随源码生成另一个会覆盖它的 README。`release/README.txt` 与用户当前发行包内的说明逐字节相同，SHA256 为：
