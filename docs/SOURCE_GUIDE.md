# 源码目录使用说明

这是 Exanima 0.9.5.2 简体中文汉化补丁的独立维护副本。汉化作者署名为李三两Owl，制作时间为2026/9月。本目录供审阅和后续上传，尚未执行上传或公开发布。

## 从哪里开始

- 构建及验证：[BUILD.md](BUILD.md)。已有译文的构建无需原版游戏文件。
- 修改中文：[TRANSLATING.md](TRANSLATING.md)。先确认编辑源文件，避免改动被生成过程覆盖。
- 重新提取原文：[EXTRACTING.md](EXTRACTING.md)。仅在需要更新文本索引时使用，自行提供相应原版游戏。
- 当前整理验证结果：[SOURCE_AUDIT.md](SOURCE_AUDIT.md)。

本目录包含原生模块源码、译文及规则、构建和验证工具、四份文本匹配索引、Noto 字体及其许可证。源码目录不是玩家安装包；玩家应下载 Releases 中的汉化 ZIP。

`data/catalog/` 的文本索引保留英文匹配键、来源、长度和偏移信息。它们用于当前版本的编译和校验，不包含原版 EXE/RPK 或其他完整游戏二进制资源。原文属于游戏内容，不能把这部分视作作者原创程序代码。

## README 与发布文件

仓库根目录未附加新的 `README.md`，以免上传本目录时覆盖你已经维护的 GitHub README。需要的开发说明都放在 `docs/`。

`release/README.txt` 从当前汉化发行 ZIP 逐字节保存。构建时原样复制进安装包，保留用户的措辞、署名和制作时间。

程序、词典、字体均需要重新构建；本目录没有捆绑编译器、已编译 DLL 或汉化 ZIP。构建产生的 `build/`、`dist/` 已加入 `.gitignore`。源码上传 Code，生成的安装包和校验文件放 Releases。

本地使用的游戏、存档、截图、运行日志、原始提取资源、历史实验补丁、下载缓存和旧工具链没有收入此目录。没有添加自动部署或 CI/CD 配置。

## 许可证状态

字体使用 Noto Serif SC 和 Noto Serif，分别保留 `assets/fonts/OFL.txt`、`assets/fonts/Latin-OFL.txt`，来源与哈希见同目录 `provenance.json`。

本次整理没有替作者选择源码或译文的开源许可证。公开源码不自动等于允许任何用途的修改和再分发；作者确认许可后，应再增加适用范围明确的许可证文件。字体的 OFL 不适用于本项目其他代码、译文或游戏原文。

## 验证范围

独立目录的自动构建和回归测试用于验证可维护性与输出一致性，不等于重新实机验收全部剧情。主菜单装饰标题和人物姓名保持原样；教程插图暂时隐藏；未知文本安全回退英文。功能范围继续以已审核发行版和实际游戏验证为准。
