# Exanima 简体中文汉化

适用于 **Exanima 0.9.5.2** 的非官方简体中文汉化补丁。下载后解压覆盖游戏目录即可使用，无需安装额外软件或系统字体。

本项目仅提供汉化补丁，不包含原版游戏。请自行准备对应版本的游戏。

## 下载

进入本仓库的 **Releases** 页面，下载版本附件中的 **Exanima-zh-CN-0.9.5.2.zip**。GitHub 自动生成的 “Source code” 压缩包不是汉化安装包。

## 安装

1. 完全退出游戏。
2. 找到包含 `Exanima.exe` 的游戏目录。
3. 如目录中已存在其他补丁的 `winmm.dll`，先备份该文件；本汉化也使用此文件名，不能直接假定二者兼容。
4. 将汉化 ZIP 内的所有文件解压到该目录，文件应直接位于 `Exanima.exe` 旁边。
5. 启动游戏，进入设置页检查中文显示。

安装后的主要文件位置：

```text
游戏目录/
├── Exanima.exe          原游戏文件
├── winmm.dll            汉化加载文件
├── ExanimaZh.dll        汉化模块
├── ExanimaZh/           译文、字体及许可证
└── manifest.json        文件校验清单
```

补丁不替换原版 EXE/RPK，也不修改存档。仅适配已校验的 0.9.5.2，其他版本不保证可用。

## 汉化范围与当前状态

已处理设置、操作、物品、技能、异能、角色对话、地图文书、竞技场和教程正文，并支持已知的装备品质／磨损、物品名前缀及动态消息。

当前版本通过 6,979 个译文输出用例、18,810 次排版测量及安装包校验，已有用户实机体验反馈。自动测试和已体验内容不等于所有剧情分支、分辨率都已验证。

已知限制：

- 主菜单等装饰标题保持原版英文，人物姓名保留原样。
- 教程插图暂时隐藏，保留占位和中文正文。
- 图片内文字、技术弹窗、未知资源或未识别的动态拼接不保证全部翻译。

## 恢复英文

退出游戏，将本补丁的 `winmm.dll` 改名为 `winmm.dll.disabled`。若安装前已有其他补丁的同名文件，请恢复事先保存的原文件。

## 反馈问题

请在本仓库 Issues 中提供游戏版本、问题截图、进入该页面或触发该句文本的步骤，并说明是否使用其他模组或补丁。截图中可见的英文装饰标题和人物姓名属于上述保留范围。
